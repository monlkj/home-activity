# 우리집 포인트

집안일과 좋은 습관을 포인트로 적립하고 가족이 정한 보상으로 교환하는 한국어 웹앱입니다.

## 실행

Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start
```

기본 포트는 3000이며 `PORT` 환경 변수로 변경할 수 있습니다. 검증은 `npm test`로 실행합니다.

가족을 선택해 활동을 완료하거나 보상을 교환하세요. 활동 완료와 교환에는 확인 창이 표시됩니다. 활동 목록과 보상 상점에서 항목을 추가할 수 있고, 가족도 추가할 수 있습니다. 기본 가족 이름은 예시이며 포인트 내역은 비어 있는 상태로 시작합니다.

데이터는 사용 중인 브라우저의 localStorage에 저장됩니다. 새로고침 후에도 유지되지만 다른 기기와 동기화되지 않으며, 브라우저 데이터를 삭제하면 사라집니다. 로그인, 부모 승인, 서버 저장은 아직 구현하지 않았습니다. 같은 기기를 사용하는 가족이 함께 기록하는 용도입니다. 실제 보상 제공은 가족 간에 진행합니다.

## Vercel 배포

이 앱은 정적 HTML/CSS/JavaScript로 동작합니다. Vercel에서는 `public` 디렉터리를 배포하며 `server.js`를 실행하지 않습니다. `vercel.json`에 별도 빌드 없이 배포하도록 설정되어 있습니다.

### 로컬에서 바로 배포

프로젝트 파일을 다운로드한 뒤 프로젝트 루트에서 다음을 실행합니다.

```sh
npx vercel login
npx vercel --prod
```

로그인 안내를 따라 브라우저에서 인증합니다. 배포 질문에서는 계정 또는 팀을 선택하고 새 프로젝트를 생성하며, 코드 위치는 `./`로 선택합니다. 프레임워크를 묻는다면 `Other`를 선택합니다. 완료 후 출력되는 프로덕션 주소를 사용하세요.

### GitHub 연결로 자동 배포

현재 프로젝트 파일을 GitHub `monlkj/home-activity` 저장소의 `main` 브랜치에 올린 다음 Vercel 대시보드에서 **Add New → Project**를 선택합니다. GitHub를 연결하고 해당 저장소를 Import합니다. Root Directory는 저장소 루트, Framework Preset은 **Other**, Output Directory는 **public**로 설정합니다. 별도 Build Command와 환경 변수는 필요하지 않습니다. Deploy를 누르면 배포되고 이후 `main` 업데이트마다 자동 배포됩니다.

배포 후 활동 완료, 새로고침 후 잔액 유지, 보상 교환을 확인하세요. 도메인이 달라지면 브라우저 저장 공간도 달라져 기존 로컬 데이터는 자동 이전되지 않습니다. 배포 주소를 아는 사람은 누구나 접속할 수 있으므로 로그인 없는 공개 앱이라는 점을 고려하세요.
